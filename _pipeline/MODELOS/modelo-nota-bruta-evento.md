# Modelo — nota bruta de varredura de eventos (`_pipeline/notas/eventos-caps-*.md`)

Uma entrada por evento encontrado. Aqui **as citações de capítulo são obrigatórias**
(o corte para prosa limpa só vale nas notas finais).

```markdown
### <Nome do evento, em inglês como a obra grafa> — caps. NNN-NNN

- **Tipo:** calamidade / guerra / cerco / abertura de herança / assembleia / torneio /
  leilão / migração de bestas / fenômeno regional / mudança de era / expedição
- **Onde:** região, terreno, nome do lugar
- **Gatilho / causa mecânica:** por que acontece dentro das regras do mundo (cap. NNN)
- **Periodicidade:** único / a cada N anos / condicionado a X
- **Duração:** (cap. NNN)
- **Escala:** quantas pessoas, que ranks, que forças (como *tipos*, não como personagens)
- **Ambiente por dentro:** fenômenos, perigos, o que se vê (cap. NNN)
- **Regras especiais do local:** supressões, bloqueios, formações, restrições (cap. NNN)
- **Prêmio / o que se ganha:** com números quando houver (cap. NNN)
- **Fases:** a ordem dos acontecimentos como estrutura, não como enredo
- **Papel possível de um grupo pequeno:** o que gente de rank baixo faz nesse cenário
- **Consequência para o mundo:** o que muda depois (estrutural)
- **Cuidado de spoiler:** o que deste evento é enredo e NÃO deve ir para a nota final
- **Lacunas:** o que a obra não informa
```

Critério de inclusão: entra o que é **maior que uma briga entre personagens** — algo que
uma vila, um clã, uma região ou o mundo inteiro sente. Uma caçada de rotina não é evento;
uma maré de bestas que faz três clãs se aliarem, sim.
