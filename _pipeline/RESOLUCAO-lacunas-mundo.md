## 4. Item 36 — Definição formal do rule path — ✅ RESOLVIDO

A passagem canônica é o **Cap. 1787 — "Rule Path Great Grandmaster"** (V5, l.141355-141395). É a exposição mais completa do path na obra inteira. Conteúdo integral do mecanismo:

**(a) Rule path é a "path-mãe" — a que mais gerou sub-paths:**
> "Because restriction path was a sub branch of rule path, it was a small path that had not been fully separated. It was like the emotion path derived from wisdom path… The truth was, **rule path had many smaller paths derived from it, it was truly the number one path without question in this regard.** The more famous ones were restriction path and phantom path. Phantom path was derived from rule path, it focused on illusions and phantoms, between truth and falsity, it had not fully separated from rule path yet."

**(b) O que é um Gu de rule path — a definição por extensão:**
> "Fang Yuan had some rule path Immortal Gu, they were **Precaution, Big, Fight**, and others. The characteristics of rule path could be easily seen from this. **Big, small, tall, short, fat, skinny, far, close, good, bad, round, square, curved, straight, truth, false, strong, weak, one, two, three, four** — these were all rule path Gu worms. **Because rule path was a huge concept, it had many branching smaller paths as a result.**"

Ou seja: rule path é o path dos **predicados/atributos abstratos** — as categorias com que se descreve qualquer coisa. Daí sua universalidade.

**(c) A consequência prática — universalidade combinatória:**
> "Among all the paths, **rule path Gu worms have the widest range of use**, or rather, they are the most practical for usage. For example, rule path Gu worm 'Strong', can be used with any path to make any killer move stronger."

**(d) O mecanismo do true meaning (o ponto pedido):**
> "Rule path had another advantage, the Gu Immortal could often **create their own true meaning** using it. This was the advantage of wisdom path as well. **True meaning involved the 'truth' of rule path, as well as the will of wisdom path.** Other than these two paths, there were truly very few Gu Immortals of other paths that could leave true meaning behind. The ten venerables were exceptions."

**Formulação mais precisa do mecanismo, encontrada no V6, Cap. 2028 — "Heaven Path Research Results":**
> "It was not easy for a Gu Immortal to leave behind true meaning. **To leave behind true meaning, wisdom path and rule path had the greatest ease. As for other paths, they had to reach a certain level of *mimicking* these paths to leave their true meaning behind.** For example, Long Hair Ancestor's refinement path true meaning or Reckless Savage's transformation path true meaning."

Isto fecha o mecanismo: não é que só rule e wisdom deixem true meaning — é que **qualquer outro path só consegue deixar true meaning ao imitar rule path ou wisdom path** até certo nível. Rule/wisdom são os dois canais nativos; os demais são derivados.

**(e) Corolário sobre herança de sub-path** (Cap. 1869, V5): "Although phantom path was only a sub-branch of rule path, **advancing phantom path attainment level was essentially still rule path true meaning.**" — cultivar o sub-path avança o attainment do path-mãe. E o inverso é o motivo do enigma inicial do cap. 1787: Tao Zhu cultivava restriction path mas deixou um **rule path true meaning**.

**(f) Limitless Demon Venerable, o Venerável do rule path** (Cap. ~1129, V5 l.30913): "Limitless Demon Venerable, however, cultivated rule path, **he wanted to use derivation Gu to derive new dao marks, eventually using these dao marks as clues to reach eternal life.**" E (V6 l.30070): "Maybe Limitless Demon Venerable researched unrestrained heavenly mark to cultivate heaven path, but **he had already become a rule path Demon Venerable at that time and could not turn back anymore.**"

**Secluded domains of heaven and earth de rule path** (V6 Cap. ~2101, l.23196): **Reverse Flow River, Cheng Bai Mountain, Miniscule Mountain** — e "Care" (o domínio do Legends of Ren Zu de onde saiu care Gu, refinado por Limitless).

## 5. Itens 9 e 42 — Os rankings de Gu supremos — ✅ RESOLVIDO (com uma lacuna residual)

**Veredito: são DUAS coisas diferentes.**

### 5.1. Uma única lista principal, com quatro traduções diferentes do mesmo nome

"Ten Big Mystical Gu" (V1 cap. 1) = "Top Ten Mystical Gu" (V3/V4) = "List of Mystical Gu" (V5/V6) = "list of mysterious Gu" (V2) — **é a mesma lista**. A prova é que Spring Autumn Cicada é 7º em todas as quatro variantes de nome:

- Cap. 1 (V1): "In the **Ten Big Mystical Gu** rankings, the Spring Autumn Cicada managed to be ranked seven"
- Cap. 202 (V2): "This Rank six gu was numbered 7 in the **list of mysterious Gu**"
- Cap. 383 (V2): "Spring Autumn Cicada is the **seventh mysterious Gu** in this world!"
- Cap. 622 e 643 (V3): "ranked seventh amongst the **top ten mystical Gu**"

⚠️ **Consequência importante:** **NÃO existe "lista dos sete Gu misteriosos"**. As expressões "seventh mysterious Gu" / "numbered 7 in the list of mysterious Gu" são a *posição 7* na Lista dos Gu Místicos, não uma lista de sete. Se o item 9/42 registrava "sete Gu misteriosos" como lista distinta, era um artefato de tradução.

**Interpretação (marcada como inferência):** o Cap. 163 diz que o 6º dos "Great Immortal Gu" vale "about the same as the Spring Autumn Cicada", que é 7º dos Mystical Gu — o que sugere listas *paralelas de escala comparável*, não a mesma lista renomeada. Mas a obra nunca explicita a relação entre elas, e as abandona. Registre-se como terminologia inicial não desenvolvida.
