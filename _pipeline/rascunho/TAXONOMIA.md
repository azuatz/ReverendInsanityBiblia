# Taxonomia dos rascunhos (documento vivo)

Regra: conhecimento se agrupa por DOMÍNIO temático amplo, nunca em arquivos soltos
por assunto. Exemplo canônico do usuário: zumbificação não é um tópico isolado — vive
dentro de "transformações e longevidade". Antes de criar um arquivo novo, consulte
esta taxonomia; se o tema couber num domínio existente, vai para lá como seção. Se um
tópico crescer demais ou se revelar parte de outro quadro, funda/mova o conteúdo e
atualize este arquivo — a taxonomia evolui junto com a leitura.
