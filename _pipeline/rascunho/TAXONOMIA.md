# Taxonomia dos rascunhos (documento vivo)

Regra: conhecimento se agrupa por DOMÍNIO temático amplo, nunca em arquivos soltos
por assunto. Exemplo canônico do usuário: zumbificação não é um tópico isolado — vive
dentro de "transformações e longevidade". Antes de criar um arquivo novo, consulte
esta taxonomia; se o tema couber num domínio existente, vai para lá como seção. Se um
tópico crescer demais ou se revelar parte de outro quadro, funda/mova o conteúdo e
atualize este arquivo — a taxonomia evolui junto com a leitura.

## Domínios atuais

| Arquivo | Cobre |
|---|---|
| `cultivo-mortal.md` | aperture, graus de aptidão e limiares, essência primeva (cores, estágios, conversões), ranks 1–5, avanço de rank, cerimônia de despertar |
| `cultivo-imortal.md` | ascensão, ranks 6–9, blessed lands/grotto-heavens, essência imortal, dao marks, tribulações/calamidades, Veneráveis (como teto do sistema) |
| `transformacoes-e-corpos-especiais.md` | zumbificação (todas as fases), corpos especiais / Ten Extreme Physiques, outras formas alternativas de existência (com referência cruzada a longevidade quando a transformação a afetar, como no caso dos zumbis) |
| `longevidade.md` | lifespan e envelhecimento, expectativa de vida por rank, lifespan Gu, métodos de extensão de vida e seus custos |
| `gu-sistema.md` | o que é um Gu, uso, alimentação, refino, fusão, receitas, Gu vitais, Gu imortais e unicidade, killer moves, empréstimo/roubo/contratos |
| `catalogo-gu.md` | tabela mestra de todos os Gu (por path), com rank/efeito/alimento/capítulos |
| `paths.md` | o que é um path + uma seção por path (filosofia, mecânicas, Gu típicos, sinergias) |
| `mundo-e-cosmologia.md` | geografia (5 regiões, 2 céus), Heaven's Will, Fate Gu, Heavenly Court, mitologia de Ren Zu (as lendas são fonte de regras do mundo) |
| `sociedade-e-organizacoes.md` | clãs (estrutura, política, status por rank), seitas, academias, righteous/demonic, alianças, cultura por região |
| `economia-e-vida.md` | primeval stones, profissões e fontes de renda, mercados/leilões, rock gambling, eventos jogáveis (trials, heranças, competições), cotidiano |
| `estudos-de-caso.md` | casos mecânicos (método, recursos, por que funcionou, exceção-ou-regra) |
| `glossario.md` | termos EN → PT com definição curta |

  sessão (cultivo-abertura, cultivo-essencia-primeva, cultivo-graus-de-aptidao,
